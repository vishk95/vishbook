# Variables and Data Types

A variable associates a name with a value.

## Primitive example

```java
int retries = 3;
boolean enabled = true;
double timeoutSeconds = 2.5;
```

## Reference example

```java
String environment = "sandbox";
```

## Comparison

| Kind | Example | Notes |
| --- | --- | --- |
| Primitive | `int` | Stores a primitive value |
| Reference | `String` | Refers to an object |

> Prefer meaningful names over abbreviations.
